# SyncCinema Browser Companion Extension (Manifest V3)

Start a synchronized couple watch party with 1 click directly from YouTube, Vimeo, anime, or video streaming sites!

---

## 🚀 How to Install in Google Chrome, Microsoft Edge, or Brave

1. Open your browser and navigate to the extensions page:
   - **Google Chrome**: `chrome://extensions`
   - **Microsoft Edge**: `edge://extensions`
   - **Brave Browser**: `brave://extensions`
2. Enable **Developer Mode** using the toggle switch in the top-right corner.
3. Click the **Load unpacked** button.
4. Select the `extension/` folder located at:
   ```
   d:\sync\synccinema (2)\synccinema\extension
   ```
5. The **SyncCinema - Watch Together** icon will appear in your browser toolbar! 🍿

---

## ✨ Features

- **1-Click Watch Party**: Click the SyncCinema icon on any video page and tap **Start Watch Party**.
- **Floating "Watch Together" Pill**: Appears automatically on supported video sites.
- **Deep Linking**: Transmits current video URL and playback timestamp directly into the room.
- **Privacy & Lightweight**: Uses Manifest V3, zero external dependencies, no user tracking.
